## What is this?

This is a self-contained, single-page web app that guides workshop participants through 6 hands-on lab exercises. Each lab challenges participants to build a real browser app in ~10 minutes using only natural language prompts with GitHub Copilot.

No installations, no frameworks, no build tools — just a browser.

---

## App Features

- **Sidebar navigation** — jump between labs at any time
- **Click-to-copy prompts** — ready-to-use Copilot prompts for each lab
- **10-minute countdown timer** — per lab, with start / pause / resume
- **Mark as Complete** — tracks progress per lab, saved in `localStorage`
- **Progress bar** — shows how many labs have been completed
- **Facilitator Tip** — advice on using natural language prompts effectively

## How to Use

### Option A — Online (recommended for participants)
Open the live URL in any browser:  
👉 [https://tantunescisco.github.io/vibe-coding-workshop/](https://tantunescisco.github.io/vibe-coding-workshop/)

### Option B — Local
Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/tantunescisco/vibe-coding-workshop.git
cd vibe-coding-workshop
# open index.html in your browser
```

No server or dependencies required.
