# 🚀 Vibe Coding Workshop — Lab Guide

An interactive, browser-based lab guide for learning to build with **Cisco CircuIT** and **GitHub Copilot**. Build real, working applications using only natural language prompts — no frameworks, no installations, just ideas and AI.

## 📋 Overview

This workshop includes **6 hands-on labs**, each designed to take approximately 10 minutes. Learn how AI-powered tools can accelerate your development workflow through "vibe coding" — the practice of using natural language to describe what you want and iteratively refining the output.

### ✨ Key Features

- ✅ **Zero Setup Required** — Runs entirely in the browser
- ✅ **HTML, CSS & JavaScript Only** — No frameworks or complex tooling
- ✅ **Copy-Paste Ready Prompts** — 30+ pre-written Copilot prompts
- ✅ **Interactive Progress Tracking** — Mark labs complete as you go
- ✅ **Fully Responsive** — Works on desktop, tablet, and mobile
- ✅ **Self-Contained** — Single HTML file, no dependencies

### Lab Details

#### Lab 1: Personal Habit Tracker 🗂️
Build a simple, interactive habit tracker that lets users:
- Add daily habits
- Mark them as complete with checkboxes
- Visualize progress with a dynamic progress bar
- Track completion streaks
- Reset habits for the next day

**Key Copilot Skill:** Iterative feature building with natural language

---

#### Lab 2: Tic-Tac-Toe Game ❌
Build a fully functional two-player game with:
- 3×3 game grid with turn-based gameplay
- Automatic win detection with visual highlights
- Draw state detection
- Restart functionality

**Key Copilot Skill:** Game logic and state management from plain English

---

#### Lab 3: Emoji Memory Match Game 🃏
Build a classic card-flipping memory game with:
- 4×4 grid of face-down cards with emojis
- Smooth CSS flip animations
- Match detection logic
- Move counter tracking
- Congratulations screen with stats

**Key Copilot Skill:** CSS animations and paired game logic generation

---

#### Lab 4: Sudoku Puzzle Game 🔢
Build a playable Sudoku puzzle with:
- 9×9 grid with pre-filled clues and locked cells
- Input validation with real-time feedback
- Solution checker
- Reset to original state

**Key Copilot Skill:** Complex grid scaffolding and validation rules

---

#### Lab 5: Interactive Quiz Builder 📝
Build a multi-choice quiz with:
- One-question-at-a-time display
- Instant feedback (green for correct, red for wrong)
- Score tracking
- Progress indicator
- Results screen with final score

**Key Copilot Skill:** Iterative prompting across layered features

---

#### Lab 6: Mini Kanban Board 📋
Build a task management tool with:
- Three-column layout (To Do, In Progress, Done)
- Add task cards via text input
- Move tasks between columns
- Delete functionality
- Counter badges per column

**Key Copilot Skill:** Dynamic DOM manipulation and layout design

## 💡 Vibe Coding Tips

### 🗣️ Be Conversational
Write prompts like you're talking to a colleague. Natural language works best.

### 🔄 Build Incrementally
Add one feature at a time. Ask follow-ups to refine and improve.

### 🎨 Describe Visuals in Plain Words
"Rounded corners," "soft blue," "center it" — Copilot understands everyday language.

### ❓ Ask Why, Not Just What
Say "explain this code" to learn alongside building. Understanding matters.

### ✨ Iterate, Don't Restart
If something's not quite right, say "That's close, but can you also..." and refine.

### 🚀 Embrace Momentum
Perfect code isn't the goal — productive conversation with AI is. Keep iterating!
